# Trilha ENEM

Lições curtas estilo Duolingo para estudar para o ENEM: trilha de unidades, cartões de ensino, exercícios variados (múltipla escolha, figura, V ou F, ligar, ordenar, completar, formato ENEM), vidas, XP, combo, ofensiva, meta diária, revisão espaçada e Desafio de fim de unidade.

**No ar:** https://jadsonbruno.github.io/trilha-enem/ (um arquivo HTML, funciona no celular e sem internet depois de carregado; o progresso fica no aparelho, com exportar/importar código).

Conteúdo reaproveitado e ampliado do Show do ENEM. As respostas são calculadas por modelos ou tabelas de fatos; as conceituais citam fontes abertas; as notas do Desafio são ilustrativas (não são TRI).

- Como acrescentar matéria, unidade ou lição: [CONTRIBUINDO.md](CONTRIBUINDO.md) e a skill `.claude/skills/nova-licao-enem/`.
- Arquitetura e contrato: [PLANO.md](PLANO.md); motor: [app/LEIAME.md](app/LEIAME.md).
- Checks: `node checks/check-tudo.mjs` · Build: `node build.mjs`.
